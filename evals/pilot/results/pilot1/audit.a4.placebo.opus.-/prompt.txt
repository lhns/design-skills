# Campus bike-share rebalancing: design record

Written by the designer with Jonas, the operations lead, in sessions on 2026-09-01 and 2026-09-08.

## Context
The campus bike-share has 12 docking stations and about 150 bikes. One van moves bikes between stations, and two staff members handle dock faults and rider problems. Stations near the library and the sports hall tend to run empty or full at predictable times.

## What Jonas said
- 2026-09-01: "Our van driver works 07:00 to 19:00, and he wants fixed runs he can plan his day around. Last year's on-call runs burned him out."
- 2026-09-01: "The library stations run empty every exam week."
- 2026-09-08: "When a station is full, people can't return their bikes and get charged for the extra time. I want staff to know quickly so someone can go and free up docks."
- 2026-09-08: "Riders should see live dock counts in the app."

## Constraints
- C1: Van runs happen at fixed, planned times between 07:00 and 19:00. (Jonas, 09-01)
- C2: Library stations get extra bikes during exam weeks. (Jonas, 09-01)
- C3: Staff learn quickly when a station is full. (Jonas, 09-08)
- C4: Riders see live dock counts. (Jonas, 09-08)

## Decisions

| Decision | Options | Ruled out by | Choice | Status |
| --- | --- | --- | --- | --- |
| D1 Rebalancing and full-station response | fixed van runs, with staff checking dock counts at each run; van and staff dispatched as soon as a station fills | dispatch as soon as a station fills: C1 | fixed van runs, with staff checking dock counts at each run | decided |
| D2 Number of van runs | three (07:00, 12:00, 17:00); four (07:00, 11:00, 14:00, 17:00) | - | three (designer default) | open, to raise with Jonas |
| D3 Exam-week loading | extra bikes left at library stations on every run; an extra run whenever a library station empties | extra run when a station empties: C1 | extra bikes on every run | decided |
| D4 Dock counts for riders | live from the dock controllers; updated after each van run | updated after each run: C4 | live from the dock controllers | forced; reported to Jonas 09-08, not asked |

## Design
The van follows the three daily runs (D2). Before each run, the planner compares each station's dock count with its target and produces a pick-up and drop-off list (D1). In exam weeks the library stations' target is raised, so every run leaves extra bikes there (D3). At each run, staff look at the dock counts and go to any full station to free docks (D1). The rider app reads dock counts directly from the dock controllers (D4).
